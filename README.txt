CASE CORNER — READY WEBSITE

Files:
- index.html       Main storefront
- style.css        Design
- config.js        Put the seller WhatsApp number here
- images/          The 3 product photos

How to use:
1. Open config.js and replace YOUR_WHATSAPP_NUMBER with the seller's WhatsApp number in international format.
2. Open index.html in a browser to preview the site.
3. Upload the whole folder to any static website host that supports HTML/CSS/JS.
4. If you want online card/UPI checkout, add a payment provider through an adult/legally compliant seller account and update the checkout flow. Do not put private payment credentials in the HTML.

Important:
- The listed prices are the current suggested prices for this draft store and can be edited directly in index.html.
- Product descriptions only describe visible features from the supplied photos; confirm material/fit claims before advertising them.
- The site uses "iPhone 15" compatibility wording and does not imply Apple endorsement.
